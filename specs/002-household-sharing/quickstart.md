# Quickstart: 002 가구와 가족 공유

002를 로컬에서 띄워 브라우저 둘로 직접 확인하는 방법입니다. 자동 테스트 실행은 끝에 있습니다. 값(키, 비밀번호, 실제 이메일)은 이 문서에 적지 않습니다. 명령은 따로 적지 않으면 저장소 루트에서 실행합니다.

## 준비물

001 quickstart의 [준비물](../001-login/quickstart.md#준비물)과 [처음 한 번](../001-login/quickstart.md#처음-한-번)을 그대로 따릅니다. 002에서 추가로 필요한 것은 아래 하나입니다.

| 항목 | 기준 |
|---|---|
| 구글 계정 둘 | 둘 다 구글 콘솔의 테스트 사용자에 있어야 합니다. 본인 계정 둘이면 됩니다. 아래에서 첫째 계정을 "계정 가", 둘째 계정을 "계정 나"라고 부릅니다 |

브라우저는 Chrome 하나로, 일반 창(계정 가)과 시크릿 창(계정 나)을 함께 엽니다. 두 창은 쿠키를 나눠 사용하지 않아 서로 다른 로그인 상태가 됩니다. 시크릿 창에서는 구글에도 계정 나로 로그인합니다.

## 앱 띄우기

001과 같습니다([앱 띄우기](../001-login/quickstart.md#앱-띄우기)). 데이터베이스는 이미 떠 있으면 그대로 두고, 앱을 다시 띄우면 Flyway가 002의 마이그레이션(`V2__household.sql`)을 적용합니다.

```bash
docker compose up -d postgres
```

```bash
./gradlew bootRun --args='--spring.profiles.active=local'
```

두 창 모두 `http://localhost:8080`을 열고 개발자 도구의 기기 화면에서 너비를 360px로 둡니다.

001에서 이미 가구 없이 로그인했던 계정이면 그대로 써도 됩니다. 처음부터 다시 하려면 데이터베이스를 삭제하고(`docker compose down -v`) 다시 띄웁니다.

## 화면에서 확인하기

각 단계의 기대 결과가 다르면 그 단계와 화면을 알려 주세요. "5분 안"은 그 창에서 구글 로그인이나 재인증을 마친 지 5분이 지나지 않았다는 뜻입니다.

앞 절을 마치면 계정 가가 owner, 계정 나가 member인 가구 하나가 있습니다.

| 순서 | 창 | 할 일 | 기대 결과 |
|---|---|---|---|
| 1 | 일반 | 주소창에 `http://localhost:8080/withdraw`를 열고 "탈퇴" 누르기 | "가구를 나가거나 삭제한 뒤 탈퇴할 수 있습니다."가 보이고 계정과 가구는 그대로입니다. 로그인한 지 5분이 지났어도 같습니다 |

| 4 | 일반 | "취소" 누르기 | 임시 첫 화면으로 돌아오고 구성원이 그대로입니다 |

| 8 | 시크릿 | 7번에서 복사한 링크 열기 | "존재하지 않는 초대 링크입니다. 가족에게 새 초대 링크를 받아 주세요."가 보입니다 |

### 만료 기간과 만료 (선택)

하루를 기다리지 않고 확인하려면 로컬 데이터베이스의 시각을 옮깁니다. 로컬 데이터베이스에만 실행합니다.

| 순서 | 할 일 | 기대 결과 |
|---|---|---|
| 1 | owner 화면에서 만료 기간 목록을 열기 | "1일"부터 "7일"까지 일곱 개이고 처음 값은 "3일"입니다 |
| 2 | 초대를 만든 뒤 아래 첫 명령을 실행하고 owner 화면을 새로 고침 | 2일 5시간이 남아 "3일 남음"입니다 |
| 3 | 아래 둘째 명령을 실행하고 새로 고침 | "1일 남음"입니다 |
| 4 | 아래 셋째 명령을 실행하고 새로 고침, 그 링크를 시크릿 창에서 열기 | 보낸 초대 영역이 사라지고 "초대 링크 만들기"가 다시 보입니다. 링크는 "만료된 초대 링크입니다. 가족에게 새 초대 링크를 받아 주세요."입니다 |

```bash
docker compose exec postgres psql -U estate -d estate -c "update invitation set created_at = now() - interval '1 day', expires_at = now() + interval '2 days 5 hours' where status = '대기'"
```

```bash
docker compose exec postgres psql -U estate -d estate -c "update invitation set created_at = now() - interval '1 day', expires_at = now() + interval '5 hours' where status = '대기'"
```


### 로그 확인

위 순서를 마친 뒤 서버 출력에서 아래가 없는지 검색합니다. 자동 테스트가 같은 것을 확인하므로 보완입니다.

## 휴대폰 실기기로 보기(선택)

001의 [휴대폰 실기기로 보기](../001-login/quickstart.md#휴대폰-실기기로-보기선택)와 같습니다. 터널 주소로 만든 초대 링크는 그 터널 주소로 만들어지므로, 링크를 연 휴대폰도 같은 터널 주소를 씁니다.

## 자동 테스트

001과 같은 명령입니다([자동 테스트](../001-login/quickstart.md#자동-테스트)). 서버 테스트가 만료 경계(시각을 옮겨 확인), 동시 수락, 다른 가구 자원 404, 응답 순서를 확인합니다.

```bash
./gradlew test
```

```bash
cd web && npm test
```

Playwright는 브라우저 컨텍스트 둘에 서로 다른 가짜 계정으로 로그인해 가구 만들기, 초대, 확인 화면과 수락, 구성원 제거, 가구 나가기, 가구 삭제, 탈퇴 409를 차례로 확인하고, 새 화면마다 360px에서 가로 스크롤이 없는지 봅니다.

```bash
./gradlew bootJar
```

```bash
cd web && npm run e2e
```
