# 0001. 기관이 공개하는 공식 API만 사용하는 결정

실거래, 청약, 단지 정보는 기관이 공개하는 공식 API에서만 받고, 공식 API에 없는 호가와 KB 시세는 사용자가 직접 입력합니다.

## 배경

이 서비스는 실거래, 청약 공고, 단지 정보, 지도를 외부에서 받아야 합니다. 사용자가 매물을 볼 때 참고하는 값 중 일부는 공식 API에 없습니다.

- 매물 호가는 부동산 앱에만 있습니다.
- KB 단지별 시세는 자금 계산에 필요하지만, 개인이 사용할 수 있는 공식 API를 찾지 못했습니다. 화면을 수집하는 방식의 상품만 찾았습니다.
- 한국부동산원도 공동주택 시세를 공개하지만, 공식 API가 없고, 자동화 수단을 이용한 시세의 대량 수집과 상업적 재배포, 제3자 제공을 금지합니다.
- 단지별 시세와 매물 호가를 기업에 파는 API 중개 상품이 있지만, 개인은 가입할 수 없고 월 요금이 있습니다.
- 부동산 앱의 단지 후기는 앱이 자동 수집을 기술적으로 막는다는 보고가 있습니다.
- 블로그와 카페 후기는 공식 검색 API로 찾을 수 있지만, 2026-09에 개정된 이용 특약이 검색 결과의 저장과 캐싱을 금지합니다. 이 내용은 특약 원문이 아니라 정리된 자료로 확인했습니다.

## 선택지

| 선택지 | 내용 | 선택 |
|---|---|---|
| 공식 API만 사용 | 기관이 공개하는 공식 API에서만 데이터를 받습니다. 호가, KB 시세, 후기는 받지 못합니다 | 채택 |
| 앱 화면 수집 포함 | 공식 API에 더해 부동산 앱 화면에서 호가, KB 시세, 후기를 자동으로 모읍니다 | 선택하지 않음 |
| 기업용 유료 API | 시세와 매물을 묶어 파는 기업 전용 API 상품에서 호가와 단지별 시세를 받습니다 | 선택하지 않음. 개인은 가입할 수 없고 월 요금이 있습니다 |
| 공식 API에 없는 값 보완 | 호가와 KB 시세는 사용자가 직접 입력합니다. 후기는 화면을 열 때 공식 검색 API로 링크만 표시합니다 | 직접 입력은 채택. 후기 링크는 이번 범위에서 뺐고, 하지 않기로 정한 것은 아닙니다 |

## 결정

- 실거래, 청약, 단지 정보는 기관이 공개하는 공식 API에서만 받습니다.
- 공식 API에 없는 호가와 KB 시세는 사용자가 직접 입력합니다.
- 지도는 무료로 사용할 수 있는 공식 지도 API를 사용합니다. 브이월드를 기본으로, 카카오맵을 대안으로 둡니다([PRD 지도 API](../prd.md#지도-api)).

## 결과

- 서비스가 받는 외부 데이터는 [PRD 외부 데이터 출처](../prd.md#외부-데이터-출처)의 공공데이터포털 API 여섯 개와 지도 API입니다.
- 호가는 사용자가 출처를 고르고 직접 입력하며, 바뀌면 이력으로 남깁니다. KB 시세는 사용자가 매물마다 입력합니다.
- 후기는 서비스에 저장하지 않습니다.
- 매물 링크를 받아 서버가 그 페이지를 읽는 방식도 화면 수집에 해당해 사용하지 않습니다.
- 실거래가 외에 공식 API로 받을 수 있는 단지 가격은 공시가격뿐입니다. 시세와 다르므로 KB 시세를 대신하지 않고, 자금 계산 화면에 참고값으로만 표시합니다([PRD 자금 계산](../prd.md#자금-계산)).

## 상태

확정, 2026-10-07

2026-10-12에 호가와 단지별 시세를 받을 수 있는 다른 공식 경로를 다시 확인했고, 결정을 유지했습니다.
