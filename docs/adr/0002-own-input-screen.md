# 0002. 기록은 서비스 자체 화면에서 입력하는 결정

임장 기록, 매물, 호가는 노션 연동이 아니라 서비스 자체 화면에서 입력하고, 1단계 화면은 웹으로 만듭니다.

## 배경

사용자는 지금 임장 기록을 노션에 남기고 있습니다. 기록을 입력하는 방식으로 노션 연동과 서비스 자체 화면 중 하나를 정해야 했습니다. 자체 화면으로 정하면 웹과 앱 중 무엇으로 만들지, 노션에 있는 기존 기록을 옮겨 올지도 정해야 했습니다.

## 선택지

| 선택지 | 내용 | 선택 |
|---|---|---|
| 노션 연동 | 노션 API로 노션에 남긴 기록을 읽어 옵니다 | 선택하지 않음. 노션 API로 읽어 오려면 기록이 정해진 템플릿 구조여야 해서 아직 고려 대상이 아닙니다 |
| 자체 화면(웹) | 서비스가 입력 화면을 직접 만들고, 웹 브라우저에서 입력합니다 | 채택 |
| 자체 화면(앱) | 서비스가 입력 화면을 앱으로 만듭니다 | 실제로 써 본 뒤 정함 |
| 기존 노션 기록 옮기기 | 노션에 있는 기록을 서비스로 한 번 옮깁니다 | 하지 않음 |

## 결정

- 기록은 서비스 자체 화면에서 입력합니다. 노션 연동은 기록이 정해진 템플릿 구조여야 읽어 올 수 있어 아직 고려 대상이 아니고, 사용자가 화면에서 직접 입력하기를 원했습니다.
- 1단계 화면은 웹 브라우저에서 동작하게 만들고, 휴대폰 화면 폭을 기준으로 합니다. 앱은 실제로 써 본 뒤 정합니다.
- 기존 노션 기록은 서비스로 옮기지 않습니다.

## 결과

- 매물 등록과 방문 일정, 호가 직접 입력과 이력, 임장 기록의 입력 화면을 서비스에서 직접 만듭니다([PRD 기능 범위](../prd.md#기능-범위)의 1단계).
- 화면 와이어프레임([`docs/design/wireframes.md`](../design/wireframes.md))은 이 결정에 맞춰 1단계 웹 화면을 그립니다.
- 앱으로 옮길지와 시점은 [PRD 열린 질문](../prd.md#열린-질문)에 있습니다.

## 상태

확정, 2026-10-12

자체 화면에서 입력하는 것은 2026-10-07에 정했고, 웹을 먼저 만드는 것과 기존 노션 기록을 옮기지 않는 것은 2026-10-12에 정했습니다.
