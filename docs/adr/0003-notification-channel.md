# 0003. 알림 채널

알림은 메일로 보내고, 카카오톡 추가는 보류합니다.

## 배경

서비스는 거래 알림, 방문 알림, 청약 알림을 보냅니다([PRD 기능 범위](../prd.md#기능-범위)). 알림 수신자는 본인과 가족 구성원, 두 명입니다. 이 알림을 보낼 채널을 정해야 했습니다.

## 선택지

| 선택지 | 내용 | 선택 |
|---|---|---|
| 메일 | 알림을 메일로 보냅니다 | 채택(기본 채널) |
| 카카오톡 "나에게 보내기" | 사용자 각자의 토큰으로 자기 자신에게 메시지를 보냅니다. 검수가 필요 없습니다 | 보류 |
| 카카오톡 "친구에게 보내기" | 한 계정에서 다른 사용자에게 메시지를 보냅니다. 검수가 필요하고 하루 발송 건수 제한이 있습니다 | 보류 |

카카오톡을 검토하며 확인한 것은 아래와 같습니다.

- "나에게 보내기"를 사용하려면 두 사람이 각자 카카오 로그인으로 메시지 전송(`talk_message`)에 동의해야 합니다. 서버는 각자의 토큰으로 호출합니다.
- 토큰이 만료되거나 동의를 철회하면 카카오톡으로 보낼 수 없습니다. 그때는 메일로 대신 보내야 합니다.
- 나와의 채팅으로 온 메시지가 휴대폰 푸시 알림으로 뜨는지는 확인하지 않았습니다.
- "친구에게 보내기"는 검수 전에는 팀멤버에게 하루 30건까지만 보낼 수 있고, 검수 후에도 발신자당 하루 100건 같은 제한이 있습니다.

## 결정

- 메일을 기본 채널로 둡니다.
- 카카오톡은 추가할지 정하지 않고 보류합니다.
- 어느 메일 발송 서비스를 사용할지는 정하지 않았습니다([C4 시스템 컨텍스트](../architecture/c4-context.md)의 외부 시스템).
- 채널을 바꾸거나 추가해도 알림 판단 로직을 수정하지 않도록 발송 채널을 별도 모듈로 분리합니다([PRD 비기능 요구사항](../prd.md#비기능-요구사항)의 알림 채널 교체).

## 결과

- 1단계의 거래 알림과 방문 알림, 2단계의 청약 알림은 메일로 보냅니다. 운영자에게 보내는 실패 알림(운영 관측, 2단계)의 채널은 아직 정하지 않았습니다.
- 카카오톡을 추가하면 사용자마다 토큰을 저장해야 하고, 카카오톡으로 보내지 못할 때 메일로 대신 보내는 경로가 필요합니다.
