# 0008. 기관마다 다른 단지 키를 연결하는 방식

1단계는 실거래의 단지 번호(`aptSeq`)만 기록하고, 다른 기관의 단지 키는 열도 두지 않습니다. 2단계에서 관심 단지를 정답으로 두고 정확도와 연결 범위를 측정해 연결 방법을 고릅니다. 열은 고른 방법에 맞춰 추가합니다.

## 배경

단지를 다루는 기관 데이터마다 단지를 찾는 키가 다릅니다([PRD 외부 데이터 출처](../prd.md#외부-데이터-출처)).

| 데이터 | 단계 | 단지를 찾는 키 |
|---|---|---|
| 아파트 매매 실거래가 상세 | 1 | 단지 일련번호 `aptSeq` |
| 건축물대장 | 2 | 시군구 코드, 법정동 코드, 번과 지 |
| 공동주택 기본 정보와 관리비(K-apt) | 2 | K-apt 단지코드 `kaptCode` |
| 청약홈 분양정보 | 2 | 단지가 아니라 공고 단위 |

- 같은 단지의 정보를 한 화면에 모으려면 기관 키를 서로 연결해야 합니다. 서로 다른 키라 연결할 규칙이 필요합니다.
- 1단계 기능(실거래 추이, 호가와 실거래 비교, 거래 알림)은 실거래 데이터만 사용합니다. 건축물대장과 K-apt는 2단계의 단지 기본 정보부터 사용합니다.

## 선택지

| 선택지 | 내용 | 선택 |
|---|---|---|
| 1단계에서 연결 방법을 정함 | 아래 세 자동 방법 중 하나를 지금 골라 1단계부터 다른 기관 키를 기록합니다 | 제외. 1단계에는 연결한 키를 사용하는 기능이 없습니다. 정확도를 측정하지 않은 채 방법을 골라야 합니다 |
| 1단계는 열만 두고 값은 비움 | 단지 테이블에 실거래 키만 기록하고, 건축물대장 키와 K-apt 단지코드 열은 비워 둡니다 | 2026-11-02까지 채택. 1단계 기능에 필요한 키는 `aptSeq` 하나입니다. 2단계에서는 열을 추가하지 않고 값만 기록하려 했습니다 |
| 1단계는 실거래 키만 두고 열도 두지 않음 | 단지 테이블에 실거래 키만 두고, 다른 기관 키의 열은 2단계에 고른 방법에 맞춰 추가합니다 | 채택. 1단계에는 두 열을 읽거나 쓰는 곳이 없습니다. 연결 방법에 따라 담을 값의 형식(한 열인지 여러 열인지, 수동 보정 표에 둘지)이 달라지므로 열의 구조도 방법을 고를 때 정합니다 |
| 주소 일치 | 실거래의 법정동과 지번을 다른 기관 데이터의 주소와 맞춥니다 | 2단계에서 비교합니다 |
| 좌표 거리 | 단지 위치를 좌표로 변환해 가까운 단지끼리 연결합니다 | 2단계에서 비교합니다. 지오코더 좌표는 저장할 수 없습니다([결정 기록 0015](0015-geocoder.md)) |
| 이름 정규화 | 단지 이름의 공백과 표기 차이를 정리한 뒤 이름이 같은 단지끼리 연결합니다 | 2단계에서 비교합니다 |
| 수동 보정 표 | 자동으로 연결하지 못했거나 잘못 연결한 단지를 표에 직접 적습니다 | 자동 방법을 보완하는 수단이라 어느 방법을 고르든 함께 둡니다. 자동 연결 결과가 없어 정확도 비교 대상은 아닙니다 |

## 결정

- 1단계는 단지 테이블(`complex`)에 실거래 단지 번호(`apt_seq`)만 기록합니다. `apt_seq`는 단지마다 하나입니다.
- 건축물대장 키와 K-apt 단지코드의 열(`bldg_key`, `kapt_code`)은 1단계 `complex`에 두지 않습니다. 2단계에 고른 방법에 맞춰 열을 추가합니다.
- 자동으로 연결하는 방법(주소 일치, 좌표 거리, 이름 정규화)은 2단계(단지 기본 정보)를 시작할 때 고릅니다. 관심 단지의 올바른 연결을 정답으로 두고, 방법마다 두 값을 측정해 비교합니다. 하나는 연결한 결과가 정답과 맞는 비율(정확도)이고, 다른 하나는 관심 단지 가운데 연결한 단지의 비율(연결 범위)입니다. 수동 보정 표는 자동으로 연결하지 못했거나 잘못 연결한 단지를 직접 적어 수정하는 보완 수단이라, 어느 방법을 고르든 함께 둡니다.
- 청약 공고는 단지가 아니라 공고 단위라 `complex`에 청약 키 열을 두지 않습니다. 청약 알림은 관심 지역의 새 공고를 대상으로 합니다([PRD 핵심 시나리오](../prd.md#핵심-시나리오) 7).

## 결과

- [데이터 모델](../architecture/data-model.md)의 `complex`에는 기관이 준 단지 키로 `apt_seq`(유니크)만 두고, `bldg_key`와 `kapt_code` 열을 뺍니다. 건축물대장 키(시군구 코드, 법정동 코드, 번과 지)와 K-apt 단지코드를 담는 열과 형식은 2단계에 고른 방법에 맞춰 정합니다.
- 2단계 계획에 자동으로 연결하는 세 방법의 정확도와 연결 범위 측정을 넣고, 이 기록을 수정해 고른 방법과 측정 결과를 남기고 상태 절에 날짜와 이유를 적습니다.

## 상태

확정, 2026-10-19

2026-11-02에 `bldg_key`, `kapt_code` 열을 1단계에 두지 않고 2단계에 고른 방법에 맞춰 추가하기로 바꿨습니다(1단계에 사용하는 곳이 없고, 열의 구조가 고를 방법에 따라 달라짐).

2026-11-02에 좌표 거리 방법은 지오코더 좌표를 저장할 수 없다는 제약을 받는다는 점을 선택지 표에 보충했습니다(결정 기록 0015가 좌표 저장을 금지함).
