## 용어

설계 문서에서 같은 대상은 이 표의 이름 하나로 부릅니다. 표의 "쓰지 않는 이름"은 따옴표로 인용한 화면 문구와 백틱 식별자, 날짜를 적은 상태 절의 옛 이름 설명에서만 남을 수 있습니다.

|---|---|---|

### 동사

산문에서 왼쪽 낱말을 오른쪽으로 바꿉니다. 화면 버튼 이름과 따옴표로 인용한 화면 문구는 그대로 둡니다.

| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 부르다, 불러(API, 메서드) | 호출하다 |
| 재다 | 측정하다 |
| 잇다(단지 키, 프레임워크) | 연결하다, 연동하다(프레임워크) |
| 빼앗다, 빼앗기다, 손에 넣다 | 탈취하다, 탈취되다 |
| 새다, 새어 나가다 | 유출되다 |
| 드러나다(비밀값) | 노출되다 |
| 끊다(세션, 토큰) | 무효화하다 |
| 쿠키가 붙다, 쿠키를 붙이다, 실어 보내다 | 전송되다, 전송하다, 담아 보내다 |
| 쿠키로 주다 | 쿠키로 발급하다 |
| 화면에 주다, 돌려주다, 답하다(API) | 반환하다, 응답하다 |
| 더하다(열, 행, 기능, 항목) | 추가하다. "키에 해제 여부를 더하면"처럼 값을 합치는 뜻은 그대로 |
| 고치다(산문 동사), 고친 시각 | 수정하다, 수정 시각 |
| 지우다(산문) | 삭제하다 |
| 다시 보다, 다시 볼 조건(결정) | 재검토하다, 재검토 조건 |
| 알아보다(거래, 개인) | 구분하다(거래), 식별하다(개인정보) |
| 좌표로 바꾸다, 위치를 찾다 | 좌표로 변환하다 |
| 부딪히다(409) | 충돌하다 |
| 잠금을 잡다, 풀다 | 잠금을 획득하다, 해제하다 |
| 세션이 끝나다 | 만료되다 |
| 한도에 닿다 | 한도에 도달하다 |
| 켜다(콘솔 설정, 프레임워크 옵션) | 활성화하다. 사용자가 알림을 켜고 끄는 뜻은 그대로 |
| 쓰다(use 뜻) | 사용하다. write 뜻은 그대로 두되, 한 표나 문단에서 두 뜻이 섞이면 write 쪽을 "쓰기", "기록"으로 |

| 옛 기록 | 이미 저장한 기록 |
| 떼어 내다 | 분리하다 |
| 기간 밖으로 밀려나다 | 재수집 기간을 벗어나다 |
| 달력이 넘어가다 | 달이 바뀌다 |
| 스크립트 주입 | XSS(스크립트 주입)를 처음 한 번 병기, 이후 XSS |
